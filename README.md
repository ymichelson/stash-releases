# Stash for Mac

Your clipboard and your voice, one notch away. Everything stays on your Mac.

**Download:** [Stash.dmg](https://github.com/ymichelson/stash-releases/releases/latest/download/Stash.dmg)

1. Open the file and drag **Stash** onto **Applications**.
2. Open Stash. The first time, macOS says it can't verify the developer: click **Done**, then go to System Settings → Privacy & Security → scroll down → **Open Anyway** → **Open**. Only once.
3. Follow the welcome screens.

Stash updates itself from here on.
